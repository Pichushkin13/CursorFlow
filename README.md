# CursorFlow

Нативное приложение для macOS / Apple Silicon: плавное перемещение курсора к случайным точкам с управлением из строки меню.

## Скачать и установить

**[Скачать CursorFlow для Apple Silicon](dist/CursorFlow_AppleSilicon.dmg?raw=true)**

1. Откройте DMG и перетащите CursorFlow на ярлык Applications («Программы»).
2. Запустите CursorFlow из папки «Программы».
3. При первом запуске приложение откроет раздел «Универсальный доступ» в настройках macOS. Включите CursorFlow.
4. Вернитесь в приложение и нажмите «Запустить».

Если приложение отсутствует в списке разрешений, нажмите «Показать приложение», затем добавьте CursorFlow кнопкой «+» в системных настройках. Приложение отслеживает изменение разрешения и обновляет статус.

Если macOS блокирует неизвестного разработчика, после попытки запуска откройте «Системные настройки → Конфиденциальность и безопасность» и используйте «Всё равно открыть», если macOS предлагает эту возможность для CursorFlow. У приложения нет Developer ID и нотариального заверения Apple. Не отключайте общую защиту macOS.

## Возможности

- Запуск, остановка и настройки через иконку рядом с часами.
- Случайные интервалы: выбранное значение от 2 до 60 секунд задаёт минимальную паузу; максимальная вдвое больше.
- Плавные перемещения в границах текущего монитора.
- Ручное движение мыши и удержание её кнопок прерывают автоматическое движение.
- Esc останавливает движение.
- Интервал сохраняется между запусками; автоматического начала движения нет.
- Кнопки перехода к разрешениям macOS и показа приложения в Finder.

Программа не кликает, не печатает, не подключается к сети и не добавляет себя в автозагрузку. Синтетическое движение курсора не гарантирует статус «активен» в Teams и других системах.

## Совместимость и проверка

macOS 11+; только Apple Silicon / ARM64 (M1 и новее). Готовый DMG не требует Rosetta, Xcode или команд в Терминале.

Структура образа, исполняемый ARM64-файл, права доступа и целостность пакета проверены. Логика движения проверена с моделированием 200 случайных траекторий, ручного управления, Escape и отзыва разрешения. **Фактический запуск и интерфейс на macOS пока не проверены.**

## Исходники и сборка

- `src/CursorFlow.c` — приложение с интерфейсом AppKit.
- `assets/` — иконки и Info.plist.
- `dist/CursorFlow_AppleSilicon.dmg` — готовый установочный образ.
- `scripts/build-macos.sh` — сборка и упаковка на Mac с Apple Command Line Tools.

Для самостоятельной сборки на Mac:

```bash
bash scripts/build-macos.sh
```

Скрипт создаёт нативный ARM64-пакет, подписывает его локальной ad-hoc подписью и формирует DMG. Такая подпись не заменяет Developer ID и нотариальное заверение Apple.
